# Laboratórios em IIoT

## 1. Introdução

Os laboratórios permitem validar conceitos teóricos por meio de experimentação prática, explorando arquiteturas reais de sistemas IIoT.

---

## 2. Pipeline de Dados IIoT

Arquitetura típica:

Dispositivo → MQTT → Processamento → Banco de dados → Dashboard

---

## 3. Simulação de Dispositivos

- Geração de dados sintéticos
- Simulação de sensores
- Testes de carga

---

## 4. Processamento de Dados

- Filtragem
- Agregação
- Transformação

---

## 5. Armazenamento

Uso de bancos de dados de séries temporais para persistência de dados.

---

## 6. Visualização

Construção de dashboards para análise:

- Métricas operacionais
- Comparações
- Tendências

---

## 7. Análise de Desempenho

Avaliação de:

- Latência
- Volume de dados
- Eficiência do processamento

---

## 8. Integração Completa

Os laboratórios consolidam a arquitetura IIoT completa, permitindo análise sistêmica do fluxo de dados.
