# Plataformas e Arquiteturas de Software em IIoT

## 1. Introdução

As plataformas IIoT são responsáveis por integrar dispositivos, processar dados e fornecer interfaces para visualização e tomada de decisão.

---

## 2. Arquitetura de Referência

Um sistema típico segue o fluxo:

Dispositivo → Comunicação → Processamento → Armazenamento → Visualização

---

## 3. Brokers MQTT

Responsáveis por gerenciar comunicação publish/subscribe.

Funções:
- Roteamento de mensagens
- Escalabilidade
- Desacoplamento de sistemas

---

## 4. Node-RED

Plataforma de orquestração baseada em fluxo:

- Integração de serviços
- Processamento de dados
- Automação de lógica

---

## 5. InfluxDB

Banco de dados orientado a séries temporais:

- Alta performance
- Armazenamento eficiente
- Consultas temporais

---

## 6. Grafana

Ferramenta de visualização:

- Dashboards interativos
- Monitoramento em tempo real
- Integração com múltiplas fontes

---

## 7. Arquitetura Integrada

A integração dessas tecnologias forma uma pipeline de dados típica:

- Coleta → Transporte → Processamento → Armazenamento → Visualização

---

## 8. Tendências

- Edge analytics
- Data-driven systems
- Integração com IA
