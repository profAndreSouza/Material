# Gabaritos — Banco de Dados I

Esta pasta reúne as respostas comentadas dos exercícios publicados nas aulas 1 a 10 e os modelos conceituais da Lista 01.

## Organização

- `aulas/Aula_01.md` a `Aula_10.md`: respostas às questões de fixação e soluções dos casos práticos.
- `Lista_01.md`: cada enunciado seguido das premissas adotadas e do respectivo diagrama PlantUML.

Os gabaritos são propostas tecnicamente consistentes, não as únicas modelagens possíveis. Onde o enunciado não fixa uma regra, a premissa adotada está indicada no arquivo correspondente.
